## 3. 지시사항 원칙 준수 여부
1. **콕핏과 100% 동일한 정품 엔카 경로 및 w5 상세 조회 유지**:
   - `MasterMappingService.generate_smart_encar_url` -> `Scraper.run(url, "")` 직접 호출.
   - 사람과 동일하게 1대씩 순차 조회 및 차량 간 18초 냉각 간격 유지.
2. **폴백 금지 (이름표 바꿔치기 금지)**:
   - 엔카 0건인 차량은 케이카 값으로 메우지 않고 `None`("데이터 없음") 처리.
   - 엔카 순위와 케이카 순위를 분리 산출.
3. **원가 기반 모델 순위 제외**:
   - 매입가를 사용하는 모델은 시장 순위에서 완전 제외.
4. **팔린 차 1대 단독 보고**:
   - 팔린 차는 1대뿐이므로 순위를 매기지 않고 단독 오차율 테이블로 분리 보고.
   - "재고 6대는 광고가가 정답이라 엔카 모델에 유리하다"는 구조적 한계 명시.
5. **성공 기준 점검 (7대 전부 encar_count > 0)**:
   - **실측 판정: ❌ 실패 (무효)**
   - 투싼 NX4(30건) 1대만 수집 성공, 나머지 6대는 `HTTP 407 (CloudFront Proxy/WAF 차단)` 발생으로 0대.
   - 지시사항 7번에 따라 0건인 채로 값을 메우지 않고 **엔카 시장 순위는 공식 "무효(INVALID)"**로 선언함.
