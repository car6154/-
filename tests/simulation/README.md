# 소매가 추정 모델 재시뮬레이션 검증 가이드 (Tests & Verification)

이 디렉터리는 매입 장부 및 광고 차량 11대를 대상으로 한 소매가 추정 모델(V2-M01 ~ V2-M26)의 재계산 및 검증용 테스트 환경입니다.

## 1. 개인정보 및 원장 보안 처리 방식
- GitHub 공개 저장소의 개인정보 보호 규칙에 따라 **실차량번호는 `CAR_01_RAY_2022`, `CAR_05_CASPER_2025` 등으로 마스킹 처리**되었습니다.
- 모델별 추정가 및 실제 판매가는 그대로 유지되어 있으므로, 차량별 오차, 절대오차(MAE), 백분율오차(MAPE), 편향(Bias)의 1:1 재계산 검증이 100% 가능합니다.

## 2. 검증 실행 방법
```bash
# 1. 즉시 오차 순위표 및 지표 재계산 검증
python tests/simulation/evaluate_simulation.py

# 2. 러너를 통한 오프라인 검증
python tests/simulation/run_simulation.py --mode offline
```

## 3. 핵심 모델 정의 및 출처
- **V2-M01 (Streamlit AI 권장소매가)**: `views/tab_main.py` [L520-560] 주행거리 회귀식 + 연식 앵커 보정 모델.
- **V2-M04 (React 콕핏 100점 벤치마크 산출소매가)**: `services/encar_service.py` [L1035-1243] `Scraper.get_benchmarked_valuation`의 `calc_individual_price` (100점 기준가에 1만km당 1.3/1.5/1.8pt 점수 감가 적용).
- **V2-M05 (React 콕핏 100점 기준소매가)**: 엔카 공식 시세리포트 기준가(`std_100_price`)와 무사고 실매물 코호트 평균가의 블렌딩 기준가.
- **V2-M07 (엔카 단순평균) / V2-M10 (엔카 중앙값)**: 엔카 동급 카드 매물의 단순 평균 및 중앙값.
- **V2-M21 (원가 + 고정 150만원 마진)**: `총원가(매입가 + 정비비 + 딜러수수료 + 기본제경비 15만) + 150만원`. 전체 MAE 34.2만원(3.3%)으로 26개 모델 중 1위.
