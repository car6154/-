# 소매가 추정 모델 재시뮬레이션 검증 가이드 (Tests & Verification)

이 디렉터리는 매입 장부 및 광고 차량 11대를 대상으로 한 소매가 추정 모델의 실측 및 검증용 테스트 환경입니다.

## 1. 지시사항 반영 및 검증 원칙
1. **콕핏과 100% 동일한 엔카 조회 경로 (`search_encar_market` -> `Scraper.run`) 적용**:
   - 콕핏의 백엔드 검색 함수와 동일한 경로로 조회를 수행함.
2. **폴백 금지 원칙 (이름표 바꿔치기 원천 차단)**:
   - 엔카 매물이 0건인 차량은 케이카 값으로 대체하지 않고 "엔카 데이터 없음(None)"으로 처리.
   - 엔카 모델 평가 시 표본에서 완전 제외.
3. **원가 기반 모델 순위 제외**:
   - 장부 매입가를 사용하는 모델(V2-M21~M25)은 시장 가격 추정 순위에서 제외함.
4. **성공 기준 판정 (11대 전부 encar_count > 0)**:
   - **판정: 미달성 (False)**
   - 11대 중 1대만 수집 성공, 나머지 10대는 `HTTP 407 (CloudFront Proxy/WAF 차단)` 발생으로 0대 수집.
   - **따라서 엔카 시장 모델 순위 산출은 무효(INVALID) 처리함.**

## 2. 엔카 0건 원인 (코드 분석)
- `Scraper.run`([`services/encar_service.py` L542](file:///c:/Users/car61/Desktop/제이프로젝트/services/encar_service.py#L542)):
  - 1번 차량 목록 수집 후 `ThreadPoolExecutor(max_workers=5)`로 매물 50여 대의 상세 API(`fetch_car_detail`)를 50회 연속 집중 호출함.
  - 이로 인해 엔카 CloudFront WAF에서 IP 레이트 리밋 / 봇 탐지가 발동되어 이후 모든 엔카 API 요청에 대해 `HTTP 407`을 반환함.
  - 화면에서 1대씩 단건 조회할 때는 정상 동작하지만, 배치 시뮬레이션으로 연속 조회할 경우 즉시 방화벽 차단에 걸리는 구조적 한계가 확인됨.
